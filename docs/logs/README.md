# Sessielogs

Eén bestand per dag: `JJJJ-MM-DD.md`, geschreven door `/einde`.
Meerdere sessies op één dag komen als losse `## Sessie HH:MM`-secties in hetzelfde bestand.

De sectie `## Volgende stap` staat altijd onderaan. `scripts/dagstart.py` leest die elke ochtend uit,
en Claude leest het nieuwste logbestand aan het begin van elke sessie (zie CLAUDE.md §10).
