## Sessie — opbouw Mainframe
**Doel:** onderzoek naar Het Mainframe (Bart Boonstra / Slim Werken AI) en een eigen, gratis Webdesign Attila Mainframe bouwen.

### Gedaan
- Onderzoeksrapport geschreven → `docs/MAINFRAME_BLAUWDRUK.md`
- Brein opgezet → `CLAUDE.md`
- Skills aangemaakt → `.claude/skills/` (dagoverzicht, nieuw-klant, website-bouwer, offerte, einde, skill-maker, structuur, tone-of-voice)
- Klantsjabloon → `klanten/_sjabloon/` + `scripts/nieuw_klant.py`
- Mainframe 2.0 web-app → `mainframe_app.html` + `start_mainframe.py` + `start_mainframe.bat` + `mainframe_config.json`
- Vanzelf → `scripts/dagstart.py`, `scripts/installeer_ochtendtaak.ps1`, `scripts/zeg_klaar.ps1`
- Persoonsgegevens uitgesloten van git → `.gitignore`

### Beslissingen
- Statussen in het CRM worden opgeslagen in `leads_status.json`; `echte_leads.csv` en `verzonden.txt` blijven onaangeroerd.
- De app luistert alleen op 127.0.0.1 en start alleen scripts die in `mainframe_config.json` staan.
- Onderhoudsprijzen, pakketinhoud, btw en betalingstermijn zijn als VOORSTEL gemarkeerd in `CLAUDE.md`.
